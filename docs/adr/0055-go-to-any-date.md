# Go to any date: Cmd+K NL + week-strip month picker

Status: accepted (2026-07-25)

Daily get-or-create already mints any `YYYY-MM-DD` (chips, week-strip pills, Today), but there was no first-class path to jump to a far or future day by typing prose ([#280](https://github.com/cameronapak/dotflowy/issues/280)). Two surfaces close the gap; both call the existing seed-free `goToDate` (ADR 0041 write-intent seeding stays Today-only).

- **Cmd+K Seam J `searchActions`:** parse the query with **chrono-node** (`chrono-node/en`, client-only) — ISO fast-path, then NL (`August 12th`, `next Monday`, `in 2 weeks`, …). Missing day → virtual row `Go to {formatDateFull}` + hint `Creates this daily note`; existing day → suppress (Fuse finds the real node). Chrono gets `forwardDate: true` by default so bare weekdays lean future, but past-leaning phrases (`last` / `ago` / `previous` / `past`) turn it off — otherwise “last Friday” rewrites to next Friday. Do **not** claim a `weekStart` option (chrono-node has none); ISO Monday ownership lives in scaffold/`date-links.ts`, not the NL parser. Key via `localDateKey` — never `toISOString().slice(0, 10)`. Ranges take the start day; time in the query is ignored for navigation.
- **Week-strip month label → month calendar popover:** click the inert “July 2026” label to pick any day in a compact Mon-start grid (purpose-built; no `react-day-picker`). Same seed-free `goToDate(…, { morph: false })` as pills. No new header calendar button.
- **`[[` picker NL is gated (ADR 0038 amend / #280 follow-on / ADR 0057).** Cmd+K stays the richer surface (scaffold period targets + catalog trio). The picker reuses the same parse stack via `parseDatePickerQuery` / `pickerDateSuggestions`, offering ISO, relatives, owned weekdays, period-start days, or chrono that is calendar-complete (day / year / **weekday**) — bare `April` stays node-search-only. Inserts `[[YYYY-MM-DD]]` tokens (not navigate). Chrono stays client-only so `date-links.ts` stays dependency-free for the Worker.
- **Rejected:** header calendar from anywhere (chrome clutter; Workflowy’s picker also lives under day chrome); Chrono on the Worker (MCP already takes ISO; “tomorrow” is the user’s local calendar); rolling our own NL regex (Obsidian still needed chrono); expanding the strip into a full month grid (ADR 0054 cut that on purpose — popover is the focused version). See ADR 0057 for weekday gate, dual period resolve, chip voice, and scaffold-only mint.
