# The date token

Status: accepted (2026-07-07)

`[[2026-07-08]]` (optional 24h time: `[[2026-07-08 14:00]]`) is a first-class inline token parsed from `node.text` — a clickable chip pointing at that day's daily note. Adopted because Workflowy's `<time>` spans are ~16% of a real export (2,683 of 16,882 nodes): degrading them to plain text would fail the OPML fidelity bar (ADR 0037), and a date-you-can-travel-to is a good outliner feature in its own right. Designed on [#120](https://github.com/cameronapak/dotflowy/issues/120).

- **Syntax**: the bracket family with a **date-shaped interior** — disjoint from `NODE_LINK_PATTERN`'s id-shaped interiors, so no collision, and hand-typed near-misses (`[[July 8]]`, `[[2026-7-8]]`) stay literal (the node-links strictness discipline). The interior IS the daily-index key (`localDateKey` format; key = first 10 chars). **Time is display + round-trip only, never identity.** No range grammar in v1 — `end*` attrs were never observed in real data; a ranged import degrades to the start date, counted.
- **Ownership**: the **daily plugin** owns the UX (Seam A widget + Seam B click) so `goToDate`/get-or-create stay module-private; the pure grammar/parse/format/suggestions live in **`src/data/date-links.ts`** (the tags / node-links core-known-format split), consumed by the OPML core, search flatten, and the `[[` picker. Rejected: a new `date-links` plugin — it would force a cross-plugin dependency to reach daily's private get-or-create. **Bounded exemption (ADR 0057):** the node-links `[[` picker may call daily-index `getMappedId` solely to suppress the mapped day uuid row when a date suggestion wins — identity lookup, not get-or-create; not a seam precedent.
- **Chip**: a BibleChip-class TSX widget with **chip voice** (ADR 0057): Today with sun icon / Tomorrow / `one day ago`…`six days ago` / `in two days`… / short absolute; hover `formatDateFull`; time after the label. Day-note badges keep Today/Yesterday/Tomorrow separately. An **atom, not folding**: no caret reveal; backspace deletes the whole token.
- **Click**: lazy `goToDate` get-or-create + zoom (the Today-button semantics). **No import-time minting** — 2,683 imported chips create zero day notes until clicked; an absent day is normal, so there is no ghost state. Rejected: navigate-only-if-exists (breaks the pointer-you-travel-through promise).
- **Creation**: hand-typed, plus date entries **folded into the node-links `[[` picker** via `pickerDateSuggestions` (today / tomorrow / yesterday + ISO + gated chrono NL). Inserts `[[YYYY-MM-DD]]` — never a uuid node link, never navigates. A separate second `[[` menu was rejected: menu-engine dispatch is first-match-wins, so it would hide date entries behind any node match. **Amended (ADR 0055 / 0057):** calendar-complete = day-of-month, explicit year, **or weekday** (owned stems + `next`/`last`); bare `April` → no date row. Period phrases insert the period-start **day**. Relatives + ISO stay in dependency-free `dateSuggestions`; chrono stays client-only in `parse-go-to-date.ts`. When a date row resolves, the mapped day node’s uuid picker row is suppressed (`getMappedId`).
- **OPML**: import keys on `<time>`'s canonical attrs (never display text); export rebuilds `<time start*>` with regenerated display text — a true Workflowy round-trip. Fallback if this token ships after import: verbatim display text, disclosed.

Rejected syntaxes: `@[display text]` (locale soup; violates the canonical-attrs rule) and bare `@2026-07-08` (prose auto-tokenizes).
