Fix AI agents connected over MCP being unable to change anything in your outline. Creating bullets worked, but checking off a to-do, editing text, collapsing a bullet, deleting, moving, and adding to the top of a list all failed with an internal error — so an agent could add notes and then never tidy up after itself. All of those work again, along with claiming a daily note. Only accounts on the upgraded sync option were affected.
