Manage expiring API keys in Connections with capture-only, read-only, or read/write access. Use personal keys with the CLI or supported MCP clients alongside OAuth. New keys default to 30 days, with a 90-day maximum; existing long-lived capture keys receive a 90-day grace period without broader permissions. Rotate keys without changing their permissions, and receive an email reminder within seven days of expiration. Selected permissions and lifetimes are clearer. Apple Shortcut setup is no longer experimental, its icon is fixed for fresh imports, and expired-key errors point to Dotflowy Settings.
